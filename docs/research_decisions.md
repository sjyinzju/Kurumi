# 初始化阶段决定

- 以实际数据盘点为本轮交付；不确定预测期限、分档、正式训练规模，不下载模型。
- 外部目录只读引用，不复制另一个数据湖；对来源代码保存内容哈希以约束复用。
- Canonical 物理版本行、当前逻辑行、Raw 行、Qlib 缓存分别计数。业务自然键相同未必是重复错误，可能是合法修订；无自然事件 ID 的来源只能按内容身份去重。
- 全量质量统计首先针对当前 active 文件的 latest 逻辑视图；它用于盘点，不是历史 PIT 特征表。后续必须先按知识时间过滤再选择版本。
- 待补齐文本正文、首次公开时间和历史版本证据后，才能设计文本增量实验。先用结构化市场数据验证数据契约和标签链路。
- 暂不新增训练框架、模型封装或评估空壳；待原生 Karpo 契约、数据范围及资源验证明确后，以最小可运行实验扩展 `src/kurumi`。
