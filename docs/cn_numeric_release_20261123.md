## 来源与计算口径

- 股本复用带公告日期的股类结构档案和 CSMAR 生效事件。A 股股本按已上市与限售 A 股合计，股类拆分须能够解释发行总数。相同结构的定期重报支持区间延续。有实际矛盾时，用股类档案与同日唯一、口径一致的日频总量解决单股类冲突。跨股类发行人估值还需已证实的股类身份、同期报价和币种换算。
- 财务按证券、财报期和原公开时点合并两个已核准的北交所增量。另从 1,753 份留存报表中核出 591 份有可用原件字段，形成 443 次已有版本的字段补充与 21 个新增版本。清晰且独立可核的合并报表字段可以直接采用。已能核算的表内恒等式出现矛盾时保留缺失。TTM 和同比按实际合格锚点及当时可得组成期重算。
- 申万归属使用旧官网 RAR、已留存的日期截面和能对应确切行业切换日的 CSMAR 指数公告。旧官网已有历史下载入口，本次以官方 RAR 的 2022-11-29 `Last-Modified` 作为该归档版本的使用起点，并以历史变更限定区间。现行回溯表用于核对有效区间。变更或母集版本无法证实时，相关行业组合依赖继续记缺。
- 市场广度、离散度、均线比例、活跃度、换手中位数和停牌占比按各自的 99% 数量覆盖计算。市场和行业组合收益仍按完整母集与 99% 前期市值覆盖发布。相对市场因子和指数状态登记 `cn.csi_all_share_gross_total_return.h00985.v1`，采用中证全指全收益 H00985，上市期龄与风险警示筛选服从指数规则。 [指数编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/20231208175438-000985_Index_Methodology_cn.pdf) · [全收益代码](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000985factsheet.pdf)
- 源档案中可以确认适用于登记在册全体持有人的实施公告，按原公布的每股送转比例更新 U。排除任一股东、回购专户或其他参与范围的情况，需要该证券的具体除权口径。停牌记录按照已知公告与生效区间选择，事后记录继续保留审计身份。限价复用归档的科创板交易规则和确切上市证据。
