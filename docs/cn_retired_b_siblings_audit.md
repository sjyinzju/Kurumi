# 五家退市 A/B 股发行人估值取证

既有历史股本锚点已经按发行人档案、CSMAR 记录与实际 A 股股本序列校核。本次重新取得相同的五份 2013 年年报，原始 PDF 的 SHA-256 与锚点记录逐份一致。年报的证券资料页分别列明 A/B 股代码。股本版本沿用对应年报原始公开日，按日精度的既有规则自下一日零时可用。

东方财富历史日行情返回 8,852 笔有实际成交量的正收盘价，复权参数为 `fqt=0`。全部记录通过深交所或上交所日历、时点、唯一键、币种及价格检查。深市 B 股以港元报价，沪市 B 股以美元报价。五只股票的 2014-12-31 收盘价亦逐一与交易所年鉴一致。[交易所报价币种说明](https://investor.szse.cn/warning/activities/stockintroduction/t20190513_567105.html) · [深交所 2014 年统计年鉴](https://docs.static.szse.cn/www/market/periodical/year/W020230915392914020630.pdf) · [上交所 2015 卷统计年鉴](https://www.sse.com.cn/aboutus/publication/yearly/documents/c/10061079/files/88330f0d1d5649549d058e800d4e18fa.pdf)

在 `cn-20796d534b7d3ba59a8054c95d4341bac4e0212ee3b50219d4f78282d5910790` 的 8,370 条候选交易日网格上运行生产发行人市值逻辑，并以真实 A/B 收盘价、原件股数和时点可用汇率独立复算。两路共得到 7,661 个相同的键，金额在 `1e-12` 相对容差内一致。所有 B 股报价使用当日收盘，摘牌后没有发行人估值。摘牌公告留作独立审计，原件股本版本继续由其实际公开时间和后续股本版本控制。

候选输入和机器核验结果在 `artifacts/cn_b_sibling_rates`。输入为 `issuer_class_versions.jsonl` 和 `class_quotes.parquet`。`share_versions.jsonl` 是上游已验证锚点的同行子集，合并时沿用原有锚点。`retired_b_audit.json` 记录原始公告、页码和 SHA-256、摘牌证据、实际价格、汇率和估值复算。复查入口为 `python -m kurumi.cn_retired_b_siblings --help`，默认从原件、报价回执与已验证汇率回放。
