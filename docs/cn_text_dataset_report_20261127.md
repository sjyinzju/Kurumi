## 新闻覆盖

- 上海证券报按原样本月取一份公司、财经和市场版，以及两份补充公司版，另取两期贯通验证版次，总计 416 个请求版次。发布保留 4,814 条新闻记录，其中 3,292 份具备可用正文与归属。2015 年旧版正文解析补回 625 个页面，其中 458 份可用于模型。报纸全文日期覆盖 2015-01-12 至 2026-06-23。 [2015 年原版样例](https://paper.cnstock.com/html/2015-01/12/content_479203.htm)
- 国家统计局遍历了 67 页公开归档和 1,000 个文章链接，普通公开请求取得 231 个成功正文响应。769 个链接在复查后仍未返回正文。研究窗口内 103 份原文满足解析和时点要求，观察覆盖 2023-02-14 至 2026-06-30。原文章的发布字段优先于迁站后的 URL 日期。 [国家统计局发布归档](https://www.stats.gov.cn/sj/zxfb/)
- 新闻合格版本共 3,395 份。部分报纸文章找不到足够可靠的历史证券或行业关联，这些记录留供审计。每个样本最多采用一条宏观、市场或行业背景新闻。

天沃科技 2022 年业绩快报修正保留了原始营业总收入 39.58 亿元、修正后的 35.91 亿元及营业利润方向。配套说明保留了融资成本补偿存在不确定性这一修正依据。公告公开日期精度为日，文本从上海 2023-06-30 00:00 可用。 [快报原件](https://static.cninfo.com.cn/finalpage/2023-06-29/1217155806.PDF) · [配套原件](https://static.cninfo.com.cn/finalpage/2023-06-29/1217155775.PDF)

全量逐月核验通过。检查覆盖样本键、发行人、证券、行业、选文版本、时点和状态。核对了 16,305 种唯一原生栏目组合、17,916 个合格正文对应的原件路径和 12 份原件的哈希及选段。2026 年 7 月文本未进入样本。历史测试加载了退市前样本 CN|CN-600146.SH|2015-04-07，并对 CN|CN-302132.SZ|2025-02-14 前后核验旧代码 300114 和新代码 302132。

39 项相关测试通过。G0、GN、GA、GNA 及自然空文本完成原生编码和 CPU packing，数值字段、60 日序列、三题七选项、Y 与监督掩码相同。原生 Readout 用小型 CPU 层验证了 B×3×7 形状及梯度链路。同批 4 个真实样本的 12 次 GNA 循环中，重新编码的中位耗时为 19.8 ms，原有每次命中写数据库为 44.1 ms，合并访问时间写入为 9.4 ms。缓存命中保留相同 token ID 和分段。正式收益训练保持未启动。 [编码短测细节](<E:/Kurumi/artifacts/cn-text/qa/encoding-benchmark.json>)
