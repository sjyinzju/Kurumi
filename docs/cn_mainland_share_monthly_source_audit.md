# 沪深交易所 A+H 月末股份原件核验

上交所和深交所的公开法定披露目录提供部分发行人提交的月报原件。两所网站法律声明允许非商业目的浏览和下载，另对以出售牟利为目的的电子抓取和传播规定书面许可。本次只在个人非商业研究工作区留存原件和核验结果。上交所使用官方繁体入口取得已公告原件，其简体附档地址在本机有过 HTTP 200 HTML 响应。深交所使用其官方披露静态域名。两路证据均保留目录和实际 PDF 的独立哈希及原件身份。 [上交所法律声明](https://www.sse.com.cn/home/legal/) · [深交所法律声明](https://www.szse.cn/application/laws/)

两所检索均请求 2014-01-01 至 2026-07-31。沪市按公告组分页并从多附件组保留实际月报附件。深市的题名页实际每页上限为 50。首次提取对每一有记录的候选选取其最早原件和 2026-06-30 截止下可得的最近原件，个别候选只有一个符合条件。175 份原件均有 HTTP 200 回执。目录命中数受发行人是否向本地交易所同步披露和题名用语影响，空目录仍作为来源缺口保留。

175 份原件中，140 份核验出完整的 A/H 普通股月底余额，共 81 对证券。上交所为 82 份、48 对，深交所为 58 份、33 对。核验月末范围为 2015-01-31 至 2026-05-31。105 份使用扣除库存股的已发行列，35 份保留当时的旧格式发行股份口径。35 份未通过，细分原因见质量 JSON。

原件第二节的普通股类别、证券代码和月底余额一并核验。现代格式逐类核对发行在外列与库存股列之和等于总发行数。早期编号样式用原件股类身份和独立的已发行列交叉核对。证券代码栏目明确标为不适用且第二节明确列 A 普通股时，A 股身份取该份原件绑定的沪深交易所证券代码。发现字面代码冲突、非零的其他普通股、版面无法解析或股类范围不全时保留失败原因。来源目录日期按日期精度处理，可用时间为次日北京时间零时。

原件验证纳入的是公告月末股份观察。它们无法单独覆盖发布日之后的逐日股本，也未证明两地任一股类的拆股累计单位因子。月末观察保留在来源层。

中国电信存在另行取得的同期发行证据。2021-08-19 上交所上市通知明确 2021-08-20 A 股上市及 A 股 77,451,093,588 股，同日发行人上市公告书列 91,328,503,588 股总额，其中 H 股 13,877,410,000 股。2021-09-25 超额配售实施公告确认增发 178,635,111 股 A，H 股未变。后版证券数量保留对应公开日。上交所原始目录、两份 PDF 及哈希保存在 `artifacts/cn_sse_class_monthly/telecom_event`。 [上交所中国电信上市通知](https://www.sse.com.cn/disclosure/announcement/listing/ipo/c/c_20210819_82626883.shtml)

可复验程序为 `src/kurumi/cn_mainland_share_monthly.py`，参数 `--pdf-python` 指向安装了 `pdfplumber` 的 Python。沪深候选查询、原件和回执位于 `artifacts/cn_sse_class_monthly/controls`、`artifacts/cn_sse_class_monthly/szse_cohort`。同一目录中的 `*_intake_summary.json` 记录逐代码覆盖和请求状态。140 条余额观察与 175 份原件检查记录位于 `artifacts/cn_sse_class_monthly/verified_broad_v2`。
