## 原始披露与生效范围

港交所主板月报规则要求发行人在月后提交证券变动月报。历史官方问答明确要求中国发行人在第二节同时列报 H 股及适用的 A 股、内资股等其他类别。月报即使没有变动也须提交。股数取第二节月底已发行余额，新格式采用扣除库藏股后的已发行列，并验证该数和库藏股合计等于总已发行数。授权股本、股份面值、优先股、潜在发行数量均保留在原件中供解释。 [主板月报规则汇编](https://www.hkex.com.hk/-/media/hkex-market/listing/rules-and-guidance/listing-rules-contingency/main-board-listing-rules/main-board-listing-rules-eng-title-tbd/consol_mb) · [港交所月报问答](https://en-rules.hkex.com.hk/sites/default/files/net_file_store/FAQs_mb_ch13_31Mar2019.pdf) · [库藏股规则生效公告](https://en-rules.hkex.com.hk/rulebook/update-no-145)

公开题名检索按实际证券内部 ID、发布日期范围和月报类别 51500 返回原始文件 URL、披露 ID、香港时间公开分钟和记录数。工商银行、招商银行分别取到 2014-01 至 2026-07 公开日范围的 151 条记录，邮储银行自 2016-09 取得 118 条。三家限量原件核验共下载 9 份 PDF，全部 HTTP 200，8 份明确确认同时存在 A/H 两类月底股数。 [港交所题名检索说明](https://www2.hkexnews.hk/-/media/HKEXnews/Homepage/Listed-Company-Publications/Search-Guide/TitleSearchGuide_e.pdf)

## 留存与复现

从 CSMAR 公司表与本地 H 股历史报价得到 211 对候选 A/H 代码，涉及 210 个 H 股候选代码，其中 203 个有报价。代码对应作为查找范围，最终关联须由原件同一发行人和同一第二节同时识别的代码与类别核对。一只 H 股候选对应两个 A 股候选，按原件分别判断。

实际试查询 210 个当前证券检索请求，208 个解析出精确 ID 并取得完整结果页，目录合计 20,718 条有效记录和 40 条标注取消记录。195 个报价关联候选有记录，13 个已解析 ID 为空。海通证券 `06837` 与拉夏贝尔 `06116` 在当前证券查找中未命中，后续通过可公开阅读的历史题名页分别确认旧 ID `69665`、`111475`，未在停采后继续下载。 [海通证券历史公开目录](https://www1.hkexnews.hk/search/titlesearch.xhtml?category=1&lang=EN&market=SEHK&stockId=69665) · [拉夏贝尔历史公开目录](https://www1.hkexnews.hk/search/titlesearch.xhtml?category=1&lang=EN&market=SEHK&stockId=111475)

试采共落盘 236 份原件的唯一 SHA-256 和 HTTP 200 响应记录，口径包括先导对照。停止前最后一个落盘检查点涉及 120 个候选，144 条通过月末普通股类别及股数核对，覆盖 100 个 H 股候选。其余未完成解析或存在类别、格式和身份问题。此范围不构成完整 2014-2026 逐日股本历史。

调查证据位于 `artifacts/cn_hkex_monthly`，与其他来源及发布版分开。`src/kurumi/cn_hkex_monthly.py` 的原件采集和复用命令要求适用书面许可下的显式参数。没有把试采数据接入 Kurumi 构建。后续工作独立检查来自上交所的信息披露原件。 [上交所网站法律声明](https://www.sse.com.cn/home/legal/)
