# 沪深北数值训练集工作记录（2026-11-26）

契约 1.2 已通过正式验收，发布状态为 `NUMERIC_READY`。最新数据包约 **4.14 GB**，可通过两套现有配置加载真实训练样本。七项核心财务齐全率从 **86.37%** 升至 **97.43%**。本轮完成数据交付和训练入口验收，模型训练保持未启动。

## 来源排查与补齐

优先复用本地申万官方历史档案、CSMAR、TuShare、BigQuant 的既有授权数据、交易所及发行人公告。BigQuant 查询前核对字段和表文档，按剩余缺口合并证券、财政期间和所需字段，同一份结果下载后本地复用。可用披露日、合并报表范围、证券身份、股类、币种和股数单位链逐项核对。历史比较列自载有该金额的报告公开时启用。

末轮本地处理为 **2,857** 个有效证券日补齐股本，为 **13,303** 个补齐发行人市值，为 **310** 个补齐财务快照，为 **47** 个补齐股数单位链，并恢复 **6** 个行业日收益。末轮财务专项又从历史发布版本、合并报表原件和可核对的现金流勾稽关系中补齐核心财务。财务专项沿用当时可得的财政季度锚点、现有标签与训练划分。

## 契约与验收

- 市场组合要求达到 **95% 证券数量覆盖**和 **95% 已知前期市值覆盖**，按有效成员重新归一化。分别记录数量覆盖、已知范围内市值覆盖和缺失。真实全市场市值分母缺乏证据时，该覆盖率保留空值。
- 行业组合按已确认成员计算，要求至少 **5 个有效成员**和至少 **3 的权重有效样本数**。保留成员覆盖和可靠性；完整成员范围未知时，完整分母保留空值。
- `NUMERIC_READY` 对训练所需核心依赖验收，增强输入允许按契约携带缺失掩码。保留 Xstock、Xmarket、Xchoice、Y、标签定义与时间切分。
- 严格配置使用样本时点可证明的行业归属。训练扩展接纳可核实的历史重建区间，并标记来源和级别。该扩展只应用于训练段；验证、校准和测试均使用严格时点版本。
